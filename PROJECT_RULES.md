# Vacation Planner project rules

Governed by https://github.com/tpoirier1969/Web-App-Standards/blob/main/UNIVERSAL_PROJECT_RULES.md

- Canonical repository: `tpoirier1969/Vacation-Planner`, branch `main`.
- Application entrypoint: root `index.html`; version source: `version.js`.
- No Supabase or other shared database writes in this preview.
- Avoid duplicate ownership of household packing, Scheduler, and campground data.
- Migrate and integrate only after schema and access review.
